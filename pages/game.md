## About

The game is an early work-in-progress. It runs in any modern desktop browser. Keyboard required, mobile is not supported yet.

## Controls

- **W / Up** &mdash; throttle
- **S / Down** &mdash; brake
- **A / D / Left / Right** &mdash; steer and lean
- **Space** &mdash; wheelie
- **M** &mdash; mute / unmute audio

## Objective

See how far you can travel before the 5 minute timer is up, or you crash! Steer to stay on the track and avoid rock obstacles, leaving the track or hitting a rock will slow you down. Logs must be wheelied over to avoid crashing, but time it well as you have to wait a short time between wheelies! If you end up in a tight spot, pivot wheelies can be done by iniatiting a wheelie while holding a direction arrow. Good luck!
